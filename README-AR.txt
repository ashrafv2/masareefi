ملفات التطبيق المستضافة في GitHub Pages لا تحتوي على بياناتك المالية الشخصية.

قبل الانتقال من النسخة التجريبية:
1. احفظ ملف JSON شاملاً (مع الصور والفواتير) من الجهاز الذي يحتوي على البيانات الصحيحة.
2. افتح الموقع الرسمي، واحفظ نسخة احتياطية لأي بيانات سابقة فيه.
3. افتح الإعدادات ← النسخ الاحتياطي واستورد ملف JSON الشامل الصحيح، ثم افحص أعداد العمليات والأرصدة والمرفقات.
4. بعد استعادة JSON تُوقف المزامنة تلقائيًا حتى تختار بنفسك «رفع بيانات هذا الجهاز» أو «استلام البيانات من السحابة». لا ترفع جهازًا فارغًا فوق نسخة سحابية صحيحة.
5. يتم ربط حساب Firebase على الموقع الرسمي مرة واحدة؛ خيار «تفعيل الاتصال التلقائي» اختياري ويتطلب جهازًا شخصيًا مؤمنًا.
6. المرفقات لا تتزامن عبر Firebase، بل تنتقل عبر النسخة الاحتياطية الشاملة.
