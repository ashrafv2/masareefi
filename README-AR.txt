مصاريفي — حزمة النشر النهائية (نسخة تجريبية قبل الاعتماد الإنتاجي)

الملفات
- index.html: التطبيق الكامل
- manifest.webmanifest: إعدادات تثبيت التطبيق
- sw.js: دعم تشغيل التطبيق دون اتصال بعد فتحه أول مرة عبر HTTPS
- icon-192.png و icon-512.png: أيقونات التطبيق

النشر عبر GitHub Pages
1. أنشئ مستودعًا جديدًا (يفضل عامًا إذا أردت رابط Pages المجاني).
2. ارفع ملفات هذا المجلد الخمسة إلى جذر المستودع.
3. من Settings > Pages اختر Deploy from a branch ثم main / (root).
4. افتح رابط HTTPS الناتج. على Safari استخدم مشاركة > إضافة إلى الشاشة الرئيسية.

البيانات والنسخ الاحتياطي
- تُحفظ بيانات التطبيق محليًا في متصفح الجهاز، ولا تتم مزامنة تلقائية.
- لحفظ البيانات سحابيًا يدويًا: الإعدادات > النسخ الاحتياطي > مشاركة نسخة إلى السحابة؛ ثم اختر Google Drive أو حفظ في الملفات > iCloud Drive.
- الاسترجاع: الإعدادات > النسخ الاحتياطي > استرجاع نسخة من الملفات، ثم اختر ملف JSON.
- لا تستورد نسخة دون التحقق؛ الاستيراد يستبدل كامل بيانات الجهاز الحالية.
- قبل الانتقال من رابط HTML محلي إلى رابط GitHub Pages: صدّر نسخة احتياطية من الملف المحلي ثم استوردها في التطبيق المنشور. المتصفح يعزل التخزين بحسب الموقع.
- لا تشارك ملفات JSON مع أشخاص آخرين؛ تحتوي بيانات مالية.

ملاحظات
- التطبيق لا يتصل حاليًا بـ Firebase أو Google Drive API ولا يرسل معلوماتك تلقائيًا إلى السحابة.
- الحفظ السحابي يعتمد على خيارات المشاركة المتاحة في جهازك وقد يتطلب نقل الملف إلى Drive يدويًا.
- يجب اختبار حفظ العمليات والاستيراد والتصدير والتثبيت على أجهزتك قبل اعتماد الإصدار للاستخدام الفعلي.
